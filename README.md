# 🚀 LML

### ابزار اشتراک‌گذاری فایل مدرن — آپلود کن، لینک بگیر، اشتراک بذار

**LML** یه ابزار اشتراک‌گذاری فایل ساده، سریع و خوش‌طرحه. فایلت رو رها کن، لینک و کیوآر بگیر، با هر کسی می‌خوای به اشتراک بذار.

## ✨ امکانات

- 📤 **آپلود Drag & Drop** — فایلت رو بکش و رها کن، با نوار پیشرفت انیمیشنی
- 🔗 **لینک کوتاه امن** — کد ۸ رقمی تصادفی با الفبای بدون ابهام (بدون `0`، `O`، `l` و...)
- 📱 **کیوآر کد خودکار** — اسکن کن و مستقیم از موبایل دانلود کن
- 📄 **صفحه دانلود اختصاصی** — هر فایل یه صفحه خوشگل با مشخصات و شمارنده دانلود داره
- 🎨 **تم شیشه‌ای (Glassmorphism)** — طراحی تیره گرادیانی با افکت ستاره‌های چشمک‌زن
- 🇮🇷 **کاملاً فارسی و RTL** — با فونت وزیرمتن
- 📱 **ریسپانسیو** — روی موبایل، تبلت و دسکتاپ عالی کار می‌کنه
- ⚡ **سبک و سریع** — بدون دیتابیس سنگین، بدون وابستگی اضافه

## 🚀 راه‌اندازی

### پیش‌نیازها
- [Node.js](https://nodejs.org) نسخه ۱۴ یا بالاتر

### نصب و اجرا

```bash
# کلون کن
git clone https://github.com/nukesamp-crypto/LML-FileSharing.git
cd LML-FileSharing/backend

# پکیج‌ها رو نصب کن
npm install

# اجرا کن
npm start
```

بعدش توی مرورگر برو به: **http://localhost:3000**

## 🔌 API

| متد | مسیر | توضیح |
|-----|------|-------|
| `POST` | `/api/upload` | آپلود فایل — خروجی: لینک + کیوآر |
| `GET` | `/api/file/:code` | متادیتای فایل + کیوآر |
| `GET` | `/api/qr/:code` | تصویر PNG کیوآر |
| `GET` | `/d/:code` | صفحه دانلود فایل |
| `GET` | `/dl/:code` | دانلود مستقیم فایل |
| `GET` | `/api/health` | وضعیت سرویس |

### مثال آپلود با curl

```bash
curl -F "file=@myfile.zip" http://localhost:3000/api/upload
```

خروجی:

```json
{
  "code": "xK7pR2mQ",
  "originalName": "myfile.zip",
  "size": 2516582,
  "link": "http://localhost:3000/d/xK7pR2mQ",
  "qr": "data:image/png;base64,..."
}
```

## ⚙️ تنظیمات

توی `backend/server.js`:

| تنظیم | پیش‌فرض | توضیح |
|-------|---------|-------|
| `PORT` | `3000` | پورت سرور |
| `BASE_URL` | `http://localhost:3000` | آدرس پایه برای ساخت لینک‌ها |
| `fileSize` | `100MB` | حداکثر حجم فایل |

> برای انتشار روی اینترنت، `BASE_URL` رو به دامنه یا IP سرورت تغییر بده.
